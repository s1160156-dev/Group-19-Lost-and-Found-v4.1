Behind the activity

This is a language-learning role play, not an automatic language assessment.

  1. Questioner: ask about the bottle body, cap and sticker shape separately. Then read all three clues back and wait for Mia to confirm before choosing.
  2. Observer: listen first. After item selection, collect exact quotations and record what you observed.
  3. Teacher: compare evidence with the dialogue. The unlock checks task completion, not language proficiency. AI feedback needs your review.

Live AI: uses the local Python server and your OpenRouter configuration. Messages are sent to the provider. Never enter children's personal data.

Rehearsal: clearly labelled, scripted responses for presentation practice. Not generative AI and not learning-outcome evidence.

Expressions are interface animations based on interaction state, not emotion recognition. Read-aloud is optional browser text-to-speech, not speech recognition.

Records stay in memory until exported. Refreshing or closing the page loses them. Export before starting a new case. Only anonymous pair codes should be used.
